# 📊 Student Outcomes Analysis

## 📌 Project Overview

This project is a **Student Outcomes Analysis** case study using Python and Pandas.

The analysis focuses on student performance, attendance, marks, data cleaning, and visualization. The main goal is to understand student performance trends and identify factors related to academic outcomes.

## 🏫 Scenario

The administration at **EduPulse University** is concerned about declining graduation rates. The dataset is analyzed to identify why students may be struggling and how attendance relates to final marks.

## 🎯 Objectives

- Calculate the average marks of students
- Identify students who scored above 75 marks
- Analyze the relationship between attendance and marks
- Calculate the correlation between attendance and marks
- Create a `Pass` column based on marks
- Count passes and failures
- Visualize the distribution of student marks
- Clean missing, duplicate, and incorrect data

## 🛠️ Technologies Used

- Python
- Pandas
- Seaborn
- Google Colab
